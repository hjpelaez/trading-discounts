# Frontend Conversion UI/UX Master (Expert Level)

## Goals
- **Cero Fricción**: Interfaces que eliminan cualquier barrera entre el usuario y el cupón.
- **Jerarquía Visual Hipnótica**: Guiar el ojo del usuario directamente a los elementos de valor (CTAs, Códigos).
- **Armonía y Espaciado (White Space)**: Uso maestro de los espacios para evitar saturación y asegurar que la interfaz sea fluida y respirable.
- **Performance Web Vitals**: Carga instantánea para retener al usuario y potenciar el SEO.

## Expert Capabilities
- **Persuasive Micro-animations**: Uso de `framer-motion` no para decorar, sino para destacar recompensas.
- **Whitespace Management**: Dominio absoluto de los márgenes y paddings para evitar que los elementos queden pegados ("cluttered"), asegurando una navegación amable.
- **Design System for Conversion**: Mantener consistencia en botones de "Pánico" vs "Ganancia", respetando siempre la identidad visual de marca.
- **Mobile-First High Performance**: Optimización extrema para dispositivos móviles.

## Expert Guidelines
- **Visual Identity Consistency**: Cada elemento debe respirar la marca Trading Discounts, manteniendo distancias coherentes (margins/paddings) entre títulos, subtítulos y párrafos para guiar al usuario de forma intuitiva.
- **Contrast & Legibility Standards**: 
    - **Modo Claro**: Usar `--border` (gris ~70% ligereza) para cajas definidas. Textos secundarios no deben bajar de contraste 4.5:1 (usar `--muted-foreground` oscurecido).
    - **Tipografía**: Evitar el recorte de descendentes (`g`, `p`, `y`) en títulos grandes con un `line-height` mínimo de `1.1`.
- **Fluid & Friendly UX**: La interfaz debe ser amigable y muy usable, garantizando que los elementos textuales guarden su debida distancia y no se sientan amontonados.
- **Component Reusability**: Componentes atómicos con "inteligencia de espaciado" integrada.
